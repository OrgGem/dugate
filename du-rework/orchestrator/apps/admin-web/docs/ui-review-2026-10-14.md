# Admin Portal UI review — 2026-10-14

This review visually checked the updated Admin Web build in a headless Chromium session against the isolated Admin shell and its in-process stub. The harness used only its synthetic admin token/session, tenant, and page-local synthetic fixtures. Browser requests stayed on `127.0.0.1`; no database, Redis, provider, real credential, or external host was used. Overview metrics unavailable in the fixture remained explicitly unavailable in the UI, so this review validates layout and interaction rather than live metric data.

## Visual findings

The pre-change baseline screenshots showed the Overview Minute–Month range controls breaking vertically at desktop width and the Businesses table headers stacking one character at a time on a 320 px viewport. The final build keeps the five Overview controls on one horizontal line at 1440 px, and all Businesses table header labels render on a single line at 320 px. The table remains horizontally scrollable for its wider columns while the document itself stays within the viewport.

At 320 px, the Connectors tab strip scrolls horizontally; the `cURL import` tab can be scrolled into view, clicked, and selected. The Security navigation exposes a reachable Secrets link at the same width. The synthetic Profiles catalog parses and its Groups tab opens at 390 px.

The New secret dialog fits horizontally at 320 px (279 px wide, 21 px left inset). Display name, Purpose, and Value controls have visible associated labels. A locally intercepted synthetic HTTP 422 response renders an inline validation alert, and Cancel closes the dialog. In the error screenshot, the alert increases the dialog content height and places its Save/Cancel footer below the initial viewport; the dialog can be scrolled to reach Cancel. This is a mobile error-state discoverability limitation to consider in a later UI pass.

## Verification

- Recursive Node UI suite: 176 tests passed across 38 suites; 0 failed.
- Focused shared primitive suite: 11 tests passed; 0 failed.
- `pnpm run build`: passed, including TypeScript `--noEmit` and Vite production build (3,052 modules). Vite reported the existing `node:crypto` browser-externalization notices and a chunk larger than 500 kB; the build completed successfully.
- Targeted Playwright check: 10 viewport states plus the modal and validation-error screenshots; 7 interaction/geometry checks passed. All captured document widths matched their viewport widths. There were 0 external-host requests and 0 uncaught page errors. The browser console recorded 12 local HTTP 404 responses from routes omitted by the narrow stub and the intentional synthetic create-secret HTTP 422 response.
- A first build attempt before the nullable-safe FormField lookup was corrected failed with TS2532; the final build above passed after that correction.
