## 4. UX/API/service contract để vận hành đủ chức năng

1. **Lưu từng nhóm độc lập:** AI, prompts, storage/retention có draft + `expectedRevision`/CAS + idempotency. Không PUT toàn bộ catalog bằng values đang mask. Secret input dùng Keep/Replace/Clear tường minh; Clear bị chặn nếu policy còn yêu cầu credential. Invalidate/reload đúng group sau write. Unsaved-change warning và diff rõ; nếu test dùng draft hoặc effective phải ghi nhãn/revision rõ.
2. **Giá trị applied:** API trả desired/effective revision, status, scope/source/owner, sanitized validation/rollout/test errors. Saved draft khác active config; báo `pending activation` tới khi service receipt xác nhận. Reconnect/restart/two replicas đọc revision thật từ authoritative store. Failure giữ draft, applied revision cũ và action retry/rollback rõ.
3. **Catalog/selector:** UI render tên client/profile/endpoint/Connector/business/account/version và lookup có scope; không yêu cầu người vận hành nhớ UUID. Có endpoint descriptions/subcases/schema; action enable/bulk disable/reset đều preview/diff/confirm. Bulk endpoint save có atomic group hoặc outcome từng endpoint minh bạch, không toast success toàn bộ khi partial fail.
4. **Connector request mapping:** typed schema cho method POST/PUT, API-key header/Bearer/NONE, prompt/file/static multipart fields, extra headers, response/session paths và timeout. `fileUrlFieldName` chỉ xuất hiện khi adapter/capability thực hỗ trợ; không coi field trong plan là UI cũ đã có. Gemini/OpenAI cần adapter hoặc validated recipe có request/response/model/usage/error tests; generic `json-http`/`multipart-http` registry không chứng minh provider parity. Overrides headers/static fields chỉ là Admin-authored frozen config, client/worker không được tự truyền URL/auth/headers tùy ý. Secret headers qua secret slots, không export raw trong recipe/override.
5. **Import cURL:** parse text có giới hạn để preview URL/method/headers/auth/form fields; không execute shell/command substitution hoặc fetch khi parse. Unsupported syntax báo rõ. Secret chỉ vào write-only staging request; không localStorage/analytics/log/cURL output. Test Connection có prompt+multi-file/status/latency/mapped response/redacted preview và timeout/size budget; readiness, credential probe và provider invocation là ba test riêng.
6. **Prompt Wizard/Test Endpoint bắt buộc:** Wizard Connector configurable (alias `ext-prompt-wizard` trong import), same tenant/account grants, cap tokens/timeout/request size; đề xuất qua Connector, hiện diff rồi accept vào draft; giữ template variables và không tự publish. Test Endpoint dùng Admin-scoped delegation tới cùng public admission/worker path, không đọc raw stored API key và không dùng platform bearer để giả client. Parameters/remote URL/upload/extensions/locks giống request thật; links operation/poll/error/usage/output/download/HITL và redacted cURL. Mock provider trong verification, external live test bounded nếu được cấp credential, không tính mock thành real provider receipt.
7. **Workflow parity:** import JSON/XML với XXE/DTD/size/depth guards, list/detail/input/node/flow/output/mapping; prompt/static forms/extra headers/response path/timeout node overrides edit-as-revision. Validate supported nodes/capabilities/bindings/cycle trước publish theo [legacy node types](../../lib/workflow-builder/types.ts); unsupported node bị từ chối rõ, không publish schema giả chạy được. P9 worker xử lý DSL/parallel/join/HITL/archive theo supported contract, Orchestrator chỉ catalog/admission/runtime. UI run qua Operations là đường hỗ trợ; không đưa legacy synchronous runner vào Orchestrator. Preview override ưu tiên với Profile/Code phải có semantics rõ và test actual request; không hai dịch vụ resolve khác nhau.
8. **Users/assignment:** create user và assignment là transaction/outbox hoặc staged workflow có trạng thái partial/retry rõ; không báo hoàn tất nếu gán quyền fail. Replace set có CAS và all-or-nothing scope validation. Disable/role/grant change revoke/refresh phiên trên replica theo policy; local password reset không áp dụng OIDC account. Legacy ADMIN/USER/VIEWER mapping thành explicit grants, không suy ra quyền từ tên role; scoped USER có thể sửa parameters/connection overrides của endpoint enabled đã giao, không core policy/credential/keys.
9. **Cleanup và operations:** Stats đọc backend thật với counts/bytes/expiry/output/refs; cleanup unreferenced/expired cache và expired output là job tách target với dry-run, bounded batch, confirm, audit/results. Eligibility kiểm refs + active lease/HITL/retry + version/storage retention trước xóa; xử lý concurrent acquisition/delete. Replay job không double-delete/miscount. Stalled recovery dựa runtime lease/fencing/reconciliation; outcome UNKNOWN không blind retry hoặc fake FAILED. Operation delete contract theo COMP, không hard-delete mọi artifacts/audit.
10. **Security/audit:** session→BFF→typed API→service; RBAC/tenant/CSRF trên read/write, no shared platform bearer impersonation; immutable real actor ID, revision/audit atomic hoặc outbox. Audit/grants phải accessible trong Admin Web (route/tab có link), không chỉ ở renderer shell cũ. Copy-once key, Vault provider credential và DB AES-GCM Profile secret giữ ranh giới cũ đã chốt; audit diff/log/exports/fixtures không chứa secret.
