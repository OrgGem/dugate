# Cost-control and runtime deployment wiring

The Connector sends reservation checks and usage settlement to the Orchestrator's private listener on port `3002`. `compose/connector.yml` pins the URL to `http://orchestrator:3002`; the listener stays on the internal Compose network and exposes no public cost-control route. Both containers receive the same dedicated `COST_CONTROL_CONNECTOR_TOKEN`. Generate a separate random value of at least 32 characters and keep it distinct from `SERVICE_IDENTITY_SECRET`, invocation keys, admin tokens, and worker tokens. Compose refuses to start when it is missing. Connector startup also refuses production when the URL/token pair is absent or partial; only the isolated restore-rehearsal bootstrap disables outbound cost-control calls.

Connector and Orchestrator use separate PostgreSQL databases. Compose provisions `du_connector`; `CONNECTOR_DATABASE_URL` may override that DSN, while `DATABASE_URL` remains the Orchestrator database. Connector migrations run against the Connector DSN.

Each Orchestrator and Connector process must receive its own slot-specific identity tuple from the trusted rollout manifest. Set the identity, slot, revision, and immutable image digest variables in `.env.docker`; configure the Orchestrator service-runtime control token separately from the Connector management identity. There are no valid identity or image defaults in the templates. Production boot rejects missing or partial tuples.

For S3 artifact storage, set `DU_STORAGE_CREDENTIAL_VERSION_REF` and `DU_STORAGE_CREDENTIAL_OWNER_TENANT_ID` to the exact managed-secret pin. Set `DU_STORAGE_ENDPOINT_ALLOWLIST` only for approved non-AWS endpoints. Prefer `DU_SECRET_CATALOG_ACTIVE_KEY_VERSION` and `DU_SECRET_CATALOG_KEYRING_JSON` from the protected deployment secret source and retain every older key version still referenced by a stored secret. When that ring is omitted, Orchestrator derives the version `encryption-key-v1` from the retained `ENCRYPTION_KEY`; configure that master with at least 32 UTF-8 bytes. An explicit ring takes priority. The template values remain blank intentionally; do not generate production key material at boot.

`DU_ADMIN_LOCAL_SERVICE_SECRET` is a separate server-only credential for local Admin sessions. `SHUTDOWN_BUDGET_MS` configures the Orchestrator shutdown chain and must remain below the Compose `stop_grace_period`.

The privileged maintenance runner is a separate host process, not an Orchestrator web container. Provision its `DU_MAINTENANCE_EXECUTION_ROLE=host`, host identity, and digest-pinned backup manifest in the host service's protected environment. It also needs its own protected `DATABASE_URL` and `REDIS_URL`, the existing Orchestrator runtime-control token, Connector management identity, and the same exact storage/keyring/recovery-key sources used to verify the pinned targets. Start the packaged `services/orchestrator/dist/maintenance-host-runner.js`; do not grant the web service a Docker socket or host manifest tools. Web routes can preview from the safe manifest projection, enqueue durable work, and read results; only the dedicated runner claims and executes backup, restore, or rollout jobs.
