## Compose changes

- `compose/connector.yml` no longer has a `ports` mapping; Connector continues listening on container port 8080 for peers on its Compose networks, and its loopback healthcheck remains.
- `compose/document-core.yml`, `compose/lc-checker.yml`, and `compose/example-review.yml` default `RUNTIME_URL` to `http://orchestrator:3002/api/runtime/v1`. Their Connector URL remains the east-west address `http://connector:8080`.
- New `compose/local-debug.yml` is not included by the root default `docker-compose.yml`. Explicitly adding it maps internal Orchestrator 3002 and Connector 8080 to loopback only, using the distinct `ORCHESTRATOR_INTERNAL_DEBUG_PORT` and `CONNECTOR_DEBUG_PORT` variables. There is no Compose profile that could publish those ports in the default stack.
- `.env.docker.example` documents the optional Runtime override and usage sink destination `http://orchestrator:3002/api/runtime/v1/usage-events`. `USAGE_SINK_URL` and `USAGE_SINK_TOKEN` remain empty by default, so usage delivery stays disabled unless configured.

The operator opt-in start command is:

```sh
docker compose --env-file .env.docker -f docker-compose.yml -f compose/local-debug.yml up -d --build
```

The example env file includes the read-only effective-config check before starting:

```sh
docker compose --env-file .env.docker -f docker-compose.yml -f compose/local-debug.yml config
```
