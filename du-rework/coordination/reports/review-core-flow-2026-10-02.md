## 2. Issues

### CRITICAL
- **C-Q1 — payload `gate:'ready'` thiếu trường bắt buộc, worker strict-parse vứt job → operation kẹt vĩnh viễn.** `submission.ts:486-494` ghi outbox chỉ `{contractVersion, deliveryId, operationId, kind, correlationId, gate:'ready'}` — thiếu `taskId, businessId, businessVersion, action` mà `BusinessJobV1Schema.strict()` (`contracts/src/queue.ts:12-24`) bắt buộc (đối chiếu nhánh submit đủ 9 field ở `submission.ts:343-355`). Chuỗi: dispatcher publish nguyên payload (`dispatcher.ts:56`) → worker `safeParse` fail → `throw invalid BusinessJobV1` (`worker-sdk/worker.ts:95-99`) → job FAILED giữ 7 ngày → `dispatched_at` đã set nên integrity-sweep thấy job alive (`runtime.ts:1310-1313`) → không re-arm. Mọi operation qua ingestion gate kẹt `QUEUED/READY` tới deadline (null = mãi mãi). Fix: ghi full `BusinessJobV1` cho ready-dispatch; test parse mọi shape outbox phía worker.
- **C-L1 — legacy download trả 200 rỗng, đánh mất bytes.** `compat/legacy-http-mount.ts:597-608`: `loadOutputContent` có bytes nhưng response trả `body:{}` chỉ kèm `content-type/content-length`, không có payload bytes (`LegacyRouteResponse.body` là `Record<string,unknown>`, `server.ts:1766-1768` không nối bytes). Client nhận 200 trống. Fix: trả bytes qua host binary path như canonical download, không qua envelope JSON.
- **C-L2 — legacy auth-failure → 500 thay vì 401.** `compat/legacy-http-mount.ts:96-106` `safePrincipal` nuốt mọi lỗi resolve thành `null`; mọi caller (`:618,:651,...`) map `null → internalError` (500). Sai key cũng 500 — sai semantics, noise alerting, lệch parity legacy (401). Fix: phân biệt no-key/bad-key → 401 legacy body, chỉ lỗi hạ tầng mới 500.

## 3. Chỗ đã đúng — giữ nguyên, đừng "sửa" thành sai

1. **Outbox + stable deliveryId + claim-fence** là xương sống đúng: at-least-once ở queue, exactly-once-effect ở runtime (CAS epoch/lease/business/state mọi write terminal: `complete/fail/saveStep/heartbeat` đều `lease_expires_at > clock_timestamp()`); `ON CONFLICT(delivery_id) DO NOTHING` mọi insert redelivery; dispatcher tách gate ingestion cả routing lẫn claim boundary (`dispatcher.ts:41` + `runtime.ts:314-316`) — defense in depth.
2. **Integrity sweep MM-05** có CAS `date_trunc('millisecond')` + EXISTS re-verify write-time + backoff mũ + cap 10 → SUSPECT + audit — chống re-arm nhầm và retry storm.
3. **Lease fencing worker-SDK triệt để**: mọi write mang `leaseEpoch`; 409 `LEASE_LOST` abort delivery, cấm provider call sau mất lease; heartbeat abort; `INVOCATION_UNKNOWN` không bao giờ blind-retry (`task-context.ts`, `document-core/worker.ts:376-402`, extract double-guard `:99-124`).
4. **Artifact integrity nghiêm**: grant expiry + version pinning + sha256 + size (`parser-budget.ts:336-348,:156-168`); bytes-vs-identity cross-check (`:349-363,:409-417`); disk-backed acquisition cap giữa luồng + zero-filled + digest re-verify (`:87-299`); envelope ghi 1 lần sha256 + stream verify (`worker.ts:110-125`); ingestion pin khớp digest+size, pin-chưa-materialize từ chối, inline text vô hiệu khi có pin (`ingest:93-137`).
5. **Ingestion consumer fencing mẫu mực**: attempt-token mọi terminal write (renew/complete/retry/escalate rowCount-guarded), commitGuard cùng tx gate, refuse boot khi claim lease ≤ transfer deadline, id deterministic + PK arbiter + verify persisted row, fail-closed non-s3 cả admission lẫn wiring.
6. **Tenant-fence nhất quán**: public read/cancel/resume 404 fixed-message (`runtime.ts:1336-1340`, `lifecycle.ts:32-35`); artifact lookup không phân biệt unknown/foreign; grant pins check tenant + READY + budget tổng bytes; metadata AAD bind (tenant, slot, row) khiến replay cross-tenant fail cryptographically, `readStored` fail-closed với plaintext; worker identity từ token timing-safe (`worker-identity.ts:41-51`), boot refuse token trùng platform credentials; route chặn worker credential lấn surface phi-runtime (`server.ts:1212-1218`).
7. **Approval/join fail-closed**: `approved` boolean bắt buộc, correction phải trỏ record tồn tại (`disbursement.ts:361-392`); evidence đủ điều kiện trước approval (`worker.ts:1061-1073`); join token khớp state lưu (`:1219-1221`); parent lock `FOR UPDATE` nên đúng 1 continuation; child fail → cancel siblings + `JOIN_FAILED`; slot trống → `CHILD_NOT_SCHEDULED` tường minh; fan-out hard ceiling 8; crosscheck counts khớp đếm thực (`:836-839`).
