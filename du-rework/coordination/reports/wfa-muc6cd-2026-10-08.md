## 2. 6d — `join.combine = 'merge'` phải merge dict, không concat array

### Finding
`businesses/document-core/src/pipelines/workflows/schema/legacy-schema-runtime.ts` join branch:
`output: node.combine === 'first' ? outputs[0] : outputs` → cả `concat` lẫn `merge` đều trả **array**.
Tham chiếu semantics (legacy `docs/workflow-schema-guide.md` §3.3): `merge | Merge object (nếu là object)`; audit G-05 (`codex-comp01-slice-g-...:207`) ghi nhận đúng mismatch này.

### Test fail-first (file mới)
`businesses/document-core/tests/wfa-runtime-join-merge.test.ts` — dựng pin hợp lệ (digest qua `canonicalLegacyWorkflowPinBytes`), chạy `handleLegacyWorkflowSchema` với schema `[input left, input right, join combine]` và context SDK tối giản; assert output cuối:

- `merge` + 2 object outputs → **`{alpha:1, beta:2}`** (không phải array) — case chính;
- `merge` + non-object outputs → giữ array (fallback tài liệu hoá);
- `concat` → vẫn array; `first` → vẫn output đầu.

RED log (`6d-red.log`): `Tests: 1 failed, 3 passed, 4 total`, exit 1 — literal:
`Expected: {"alpha":1,"beta":2} / Received: [{"alpha":1},{"beta":2}]`.

### Fix
Thêm helper và dùng trong join branch:

```ts
function combineJoinOutputs(combine: unknown, outputs: readonly unknown[]): unknown {
  if (combine === 'first') return outputs[0];
  if (combine === 'merge' && outputs.length > 0 && outputs.every((output) => isRecord(output))) {
    return Object.assign({}, ...outputs);
  }
  return outputs;
}
```

```diff
-        output: node.combine === 'first' ? outputs[0] : outputs,
+        output: combineJoinOutputs(node.combine, outputs),
```

Quyết định semantics (ghi trong doc comment helper):
- `merge` chỉ merge khi **mọi** output là plain object (đúng "nếu là object"); nếu có output không phải object → giữ array để không rơi dữ liệu.
- Xung đột key resolve như object spread: **source sau thắng**.
- `concat`/absent giữ nguyên hành vi cũ (array); `first` giữ nguyên.
