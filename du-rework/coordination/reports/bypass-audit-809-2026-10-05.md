## 4. Decrypt failure versus plaintext compatibility

Recognized sealed values: [metadata-crypto:287-319](../../services/orchestrator/src/modules/runtime/metadata-crypto.ts#L287) unwrap failure, AAD mismatch and GCM tag failure throw; readStored returns open(...) directly. readStoredText:371 has no catch around the authenticated open. Ingestion:636-643/666-671 retries only provider outage or escalates; it does not acquire using a plaintext fallback after an authenticated failure. Migration toLockedPayload:914 classifies an open failure unresolved with plaintext=null, blocking completion. Prompt carrier requires strict read false and validated shape.

Two other paths must not be confused with that safe failure behavior: (a) malformed/unrecognized JSON/shape under current true flags returns a legacy value, so a damaged discriminator can change the branch before decryption; central deny must treat suspicious malformed envelopes explicitly. (b) checkpoint output:1913 uses openedOutputRef ?? rawOutputRef after a **successful nullish result**, not after a thrown decrypt error. It must enforce the expected opened-string postcondition rather than re-expose stored data. BA-01 never reaches authenticated open for TEXT, so the absence of catch/fallback does not make it safe.

## 5. Export, SQL, logs, audit, telemetry and cache conclusions

No production Drizzle metadata SELECT or slot-specific pg_dump/COPY/export implementation was found in the scoped rework source/scripts. This does not restrict an operator with DB credentials: SELECT/COPY/backup can copy plaintext legacy rows without calling any application reader or A12 helper. DB role restrictions, controlled encrypted backups and documented privileged inspection are separate pre-flip responsibilities.

Maintenance shape SQL selects aggregate predicates only, not values ([counter SQL](../backfill-leftover-counter-803.sql)); its shape-pass/PASS is **not** authenticated protection evidence. Auth counter legitimately loads values to authenticate but returns counts/categories, never raw values. It is read-only; it is not an auth middleware, a plaintext policy or a production job entrypoint.

Checked operations list/status/legacy projections omit the8 metadata fields. Legacy output_content/pipeline/steps/error data are separate plaintext columns, not coverage proof for metadata slots; this audit does not pronounce that wider document-content seam protected. No slot plaintext was found flowing into current logger/audit/telemetry/cache sinks by the traced paths. This negative observation is bounded: injected error text BA-08, whole-row APIs BA-07 and future exports require explicit no-secret tests; it is not a proof over arbitrary plugins, logs at runtime or all cache implementations.
