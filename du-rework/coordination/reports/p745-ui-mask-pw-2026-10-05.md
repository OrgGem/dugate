## 2. New test (tests/browser/admin-web/p745-ui-mask.spec.ts, 2 cases)

1. **masked by default, click reveals, click hides again** (the acceptance):
   - Paste `curl -X POST ... -F author=Nguyen -F api_key=hiddenvalue1 -F model=gpt-4o` into the modal textarea.
   - Assert the Imported form fields table does NOT contain `hiddenvalue1`, shows `****lue1`,
     and DOES show the non-dictionary fields (`Nguyen`, `gpt-4o`) - the heuristic boundary, at runtime.
   - One `Show value for api_key` button, zero `Hide ...` buttons.
   - Click Show -> the table now contains `hiddenvalue1`, `Hide value for api_key` appears, Show is gone.
   - Click Hide -> `hiddenvalue1` gone again, `****lue1` back. Ends with `expect(errors).toEqual([])` (no pageerror).
2. **header table offers no reveal control** (hard rule): paste a `-H content-type: application/json`
   command; the headers table renders, never shows the raw header value (`set (16 chars)` only),
   has exactly 2 `th` (Name, Value - no Reveal column), and zero buttons. Snapshot 745-04.
