## 2. Review of STUB-EXT Delta (`connectors-screen.tsx`)

In `coordination/reports/stub-ext-2026-10-05.md` §3, lane `dsh_2` identified that prior to `STUB-EXT`, connector action mutations failed with 403 `CSRF_REJECTED` because `connectors-screen.tsx` omitted `client.getSession()` during initial bootstrap.

### Inspection of the surgical fix:
- **`connectors-screen.tsx:125-130`**:
  ```tsx
  const sessionResult = await client.getSession();
  if (!sessionResult.ok) {
    setSessionFailed(true);
    setCapabilities({ kind: 'failed', problem: sessionResult.problem });
    return;
  }
  ```
- **Security Assessment**:
  1. The session read is performed immediately on mount before capabilities or list fetching.
  2. If the session fails, `setSessionFailed(true)` triggers `<AlertBanner variant="warning" title="Admin session unavailable">`, explicitly explaining that *"connector management needs the signed-in admin session (writes ride the BFF with the server-issued CSRF proof), so every write stays disabled."*
  3. All action buttons remain fully disabled (`fail-closed`).
  4. The fix requires zero changes to the shared `client.ts` or contracts, preserving static security guards (`p745-ui-keys.spec.ts:136-150`).
- **Conclusion on Delta**: **APPROVED** under Coordinator Adjudication A1.
