## 2. CRX-02 — policy bắt buộc mã hóa cho MỌI read dependency

- `server.ts:626-647` — nguồn policy duy nhất:
  - `encryptedWritesRequired = s3 + backend s3 + publicUploadEncryption` (encrypted upload gateway là write path duy nhất của platform trên S3);
  - `artifactMigrationWindowOpen = backend s3 && migrationWindow === true` (narrowing đúng union type);
  - `artifactEncryptionRequired = encryptedWritesRequired && !artifactMigrationWindowOpen`;
  - `artifactDecryptDeps` (instance DUY NHẤT, dùng cho cả 2 route) nhận `encryptionRequired: artifactEncryptionRequired`.
- `server.ts:364-369` — doc ngay tại `artifactStorage.migrationWindow`: flag này là **policy migration được operator ký** — khi mở, object cũ (thiếu marker) vẫn đọc; khi đóng, read path **bắt buộc marker → fail closed**. Không nhánh boot nào mặc định mở.
- Audit: `artifactDecryptDeps` chỉ được tạo 1 lần (`:644`), truyền vào RouteContext (`:887`), dùng tại đúng 2 call site (`:1655` runtime GET, `:2192` public download) — policy phủ **mọi** read path (grep `artifactDecryptDeps|ArtifactDecryptDeps` trong `src/` xác nhận).

## 3. RFX-05-residual — manifest version xuyên suốt adapter + call site

- `server.ts:209-225` — `s3StoredObjectReader.readManifest(manifestKey, versionId?)`: khi có `versionId` thì `GetObject({Bucket, Key, VersionId})`; `undefined` giữ nguyên hành vi cũ (key-only). Vẫn bound `MAX_MANIFEST_BYTES` + JSON parse + 503 như cũ.

- `server.ts:2156` + `:2176-2196` — public download SELECT thêm `a.manifest_version_id`, row type + ref nhận `manifestVersionId: row.manifest_version_id`.
