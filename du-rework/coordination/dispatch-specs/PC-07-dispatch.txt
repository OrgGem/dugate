CORE REQUIREMENTS (from Plan §PC-07 and Security Rules):
1. Admin-Only Fresh Execution & Ownership Preservation:
   - Retry creates a fresh execution row with new UUID, but preserves the original `api_key_id`, idempotency owner, config snapshot (`profile_policy_snapshot`, `profile_id`, `profile_revision`), manifest/workflow revision, connector pins, callback policy, and prompt overrides.
   - `retry_of` points to original operation id.

2. Strict Reauthorization Before Coalesced Replay & Before Insert:
   - For all operations, reauthorize before coalesced replay check AND before fresh insert.
   - Verify `api_key_id` status: must be `ACTIVE`. If the original key was globally revoked or does not exist, reject retry with 409 conflict (`API_KEY_REVOKED` or `KEY_INACTIVE`).
   - For `GROUP_MANAGED` keys:
     * Check root grant for `(tenantId, groupId, apiKeyId)`: must exist, have state `ACTIVE`, not revoked.
     * Verify the endpoint/function is enabled in the current profile group config. If disabled or removed, reject retry with 409 conflict (`ENDPOINT_DISABLED` or `GRANT_REVOKED`).
   - For standalone/legacy profiles:
     * Recheck profile / key spend admission.

3. Cryptographic Carrier Re-encryption (Anti-tamper / AAD Isolation):
   - Re-decrypt input (`operations.input_ref`), payload (`tasks.payload_ref`), prompt overrides (`operations.prompt_overrides_ref`), and sourceUrl with old AAD (`operationId` / old `taskId`).
   - Re-seal each carrier against the NEW operation/task AAD (`newId` / `taskId`).
   - NEVER copy ciphertext directly between operations/tasks.

4. State & Replay Invariants:
   - Unknown provider outcome (`INVOCATION_UNKNOWN`, `op.state === 'UNKNOWN'`, task `UNKNOWN`) stays strictly blocked.
   - In-flight operations continue on pinned snapshots; completed operations can be replayed if concurrent.

5. Verification & Tests:
   - Author comprehensive unit/integration suite in `tests/profile-control-plane-retry.test.ts`.
   - Cover:
     * Successful retry under active key + active group grant.
     * Deny retry when key is revoked.
     * Deny retry when group root grant is revoked.
     * Deny retry when function is disabled in profile group.
     * Ensure carrier re-encryption binds to new AAD.
     * Coalescing behavior re-authorizes.
