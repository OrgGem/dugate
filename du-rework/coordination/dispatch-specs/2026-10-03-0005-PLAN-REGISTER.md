# PLAN-REGISTER — Kiểm kê ĐẦY ĐỦ task chưa xong trên mọi plan file (READ-ONLY)

**Mục tiêu:** tạo danh sách **xác thực** mọi task/dòng chưa hoàn thành (`[ ]`, `[~]`, hoặc tương đương) trên toàn bộ plan file trong `du-rework/tasks/*.md`, để coordinator điều phối tiếp.

**File lease:** READ-ONLY với mọi source/test/docs; CHỈ ghi `du-rework/coordination/reports/plan-open-task-register-2026-10-03.md`.

## Việc

1. Quét `du-rework/tasks/*.md` (tất cả file, kể cả file cũ). Với mỗi file:
   - liệt kê các dòng/khối task chưa xong: ID (vd CONV-03, RFX-11, ACUI-04, P8-02…), trích status marker, **file:line**, 1 dòng mô tả.
   - phân loại: `implementation-open`, `verification-open`, `docs-open`, `decision-gated` (nêu ai/cái gì chặn), `infra-gated` (live/lab), `stale-suspected` (dòng có thể đã xong nhưng chưa tick — nêu bằng chứng nhẹ nếu thấy từ receipt/commit gần đây).
2. Đối chiếu nhanh với `coordination/reports/` các receipt gần đây (tên file là đủ) để gắn cờ `stale-suspected` cho các item đã có receipt.
3. Ghi tổng hợp cuối: bảng đếm theo plan + theo phân loại. KHÔNG tick/sửa bất kỳ file plan nào.

## Acceptance

- Với mỗi plan file: có mục riêng; các dòng chưa xong có `file:line`; không bỏ sót file nào trong `tasks/` (liệt kê file đã quét + số dòng tìm thấy).
- Không overclaim: chỗ không chắc ghi `uncertain`.

## Ranh giới

- Không tick gate; không commit; không nhắm `nocobase-10`.
- Receipt: chính là file register nêu trên (kèm mục phương pháp).
