## 3. Thu tu chay va dieu kien dung

```
L0  build + boot            <- bat buoc xanh truoc moi thu khac
 L1 auth                    <- nen cho moi request L2+
  L2 registry + version     <- can version active truoc L4
   L4 profile/api-key/wf    <- can binding truoc moi pipeline
    L5 pipeline day du      <- KET QUA co y nghia neu stack chay khong loi
     L6 workflow DAG
      L7 security
       L8 UI
        L9 fault injection
```

**Quy tac dung:**
1. **L0 khong xanh → dung ngay.** Khong chay L1+ tren stack chua boot.
2. **L1.5 that bai → dung truoc L4.** Le `fence server.ts:318-324` la ha tang bao mat; build ma khong no = sai truc tiep.
3. **L2.6 that bai → dung truoc L5.** He thong chon sai version ngam la lo hong, khong phai loi UI.
4. **L5.7 byte-equal that bai → dung truoc L8.** Wire base64-wrap la loi du lieu.
5. **L3 expected-fail khong chan chuoi** (vi no la behavior co chu dich), **nhung L3.3 phai xac nhan** bang grep.
6. **L9 chi chay khi L0–L8 xanh** — neu lao vao fault injection som, ba loi mau thong bao bao gio la loi can ban.
